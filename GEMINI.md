# GEMINI.md — ASTRA

Este repositorio se rige por `AGENTS.md`. Léelo completo antes de actuar; las skills están en `.agents/skills/` (copias generadas desde `skills/`).

Las cinco reglas que no se rompen, repetidas aquí para que ningún runtime las pierda:

- Español latino neutro, sin voseo; identificadores y comandos en inglés.
- Nunca escribir claves, semillas, mnemónicos ni datos personales; solo vectores públicos como ejemplos.
- Toda URL, chainId, RPC o estándar nuevo se verifica en vivo y se anota la fecha.
- Las skills se editan en `skills/` y se sincronizan con `astra skills sync`; las copias no se editan a mano.
- ASTRA no menciona ni depende de otros protocolos, memorias ni daemons.
