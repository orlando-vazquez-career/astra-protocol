# Guías de ASTRA

Cómo ejecutar cada parte del protocolo. El *qué* y el *por qué* viven en `ASTRA-PROTOCOL.md`; aquí está el *cómo*.

| Guía | Cuándo leerla |
|---|---|
| [`gates.md`](./gates.md) | Antes de aprobar la Carta (Gate 1) y antes de firmar el lanzamiento (Gate 2). |
| [`keys-and-secrets.md`](./keys-and-secrets.md) | Al crear el primer alias de claves, y cada vez que un agente vaya a firmar algo. |
| [`audit-checklist.md`](./audit-checklist.md) | En la fase Auditoría; el auditor lo recorre completo. |
| [`standards-map.md`](./standards-map.md) | En Órbita y Carta, para elegir el estándar antes de inventar (A5). |
| [`agentic-payments.md`](./agentic-payments.md) | Si el proyecto cobra o paga por request entre máquinas (x402, MPP). |
| [`runtimes.md`](./runtimes.md) | Al configurar el runtime de IA (Claude Code, Codex, Kimi, Cursor, Gemini, OpenCode). |
| [`skills-externas.md`](./skills-externas.md) | Para instalar packs de skills de terceros en un proyecto ASTRA. |
| [`chains/stellar.md`](./chains/stellar.md) | Proyectos en Stellar / Soroban. |
| [`chains/syscoin.md`](./chains/syscoin.md) | Proyectos en Syscoin: L1 UTXO, NEVM o Rollux. |
| [`chains/base.md`](./chains/base.md) | Proyectos en Base. |
| [`chains/evm-generico.md`](./chains/evm-generico.md) | Cualquier otra cadena EVM, y cómo agregarla al registro. |

Toda URL, chainId o RPC de estas guías se verificó en vivo el 2026-09-04. Si algo cambió, la guía se corrige y se anota la nueva fecha.
